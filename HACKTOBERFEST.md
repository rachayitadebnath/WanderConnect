# Hacktoberfest — How to contribute to WanderConnect

Welcome! If you want to contribute to WanderConnect for Hacktoberfest, here's how to get started.

1. Look for issues labelled `good first issue`, `help wanted`, or `hacktoberfest`.
2. If you find something you'd like to work on, comment on the issue to say you're taking it.
3. Fork the repo, create a branch, make a small focused change, and open a PR against `main`.
4. Make sure your PR follows the CONTRIBUTING guide and the PR checklist.

Tips

- Small, well-documented PRs are more likely to be accepted.
- If you are changing behavior, include steps to test and any relevant screenshots.

Maintainers: please label issues you want included in Hacktoberfest with the `hacktoberfest` label and consider marking beginner-friendly issues with `good first issue`.

Happy hacking!
