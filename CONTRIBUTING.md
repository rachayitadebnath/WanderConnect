# Contributing to WanderConnect

Thank you for your interest in contributing to WanderConnect! We welcome contributions of all sizes — from reporting bugs and improving documentation to fixing issues and adding features.

How to contribute

1. Fork the repository and create a branch from main: `git checkout -b my-feature`.
2. Follow the issue templates when opening issues so maintainers have the context they need.
3. Make small, focused changes and include tests where applicable.
4. Commit messages should be clear and follow this format: `type: short description` (e.g., `fix: correct map marker placement`).
5. Open a Pull Request against `main` and fill out the PR template.

Code review

- PRs should include a clear description of changes and how to test them.
- Maintainers will review and request changes if necessary.

Labels we use (please help maintainers by applying them when appropriate)

- good first issue — Issues that are suitable for new contributors.
- help wanted — Issues where maintainers welcome external help.
- hacktoberfest — Issues targeted for Hacktoberfest contributions.
- documentation — Docs-related changes.
- enhancement — New features or improvements.
- bug — Bug fixes.

Community

By contributing you agree to follow our Code of Conduct: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

Thank you for helping improve WanderConnect!
